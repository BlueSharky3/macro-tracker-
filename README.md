# Nutrition Macro Tracker

Open `index.html` in a browser to use the tracker on this computer.

## Install on a phone

This is now a Progressive Web App. To install it like an app, the folder needs to be served from a web address, not opened as a plain file.

Simple options:

1. Upload the folder to a static host such as Netlify, Vercel, GitHub Pages, or Cloudflare Pages.
2. Open the hosted link on your phone.
3. On iPhone Safari, tap Share, then Add to Home Screen.
4. On Android Chrome, open the menu, then tap Install app or Add to Home screen.

Your custom foods, daily log, and history are saved in that browser on that device.
